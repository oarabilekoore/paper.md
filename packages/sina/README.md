# p4p3r Sina - Training Tool 

Named after the last wall in Attack on Titan. This packages contains all necessary code that allows for;

0. Training ML models 
0. Benchmarking models
0. Compare model benchmarks 
0. Scan documents and perform saves
0. Create varied synthetic images
0. View the database 
0. Run SQL commands on the database 
0. Update dataset properties on the database 

This is provided on a front-end written in Javascript, Droidscript hybrid ui framework and Python FastAPI.
